# disability-job-search

障害者雇用の求人を探す人が、希望する職種と勤務地で求人候補を絞り込み、企業の公式募集ページを確認できるWebアプリをPythonで作るプロジェクトです。現在は、本体で使う処理を `training/` の練習問題で一つずつ学んでいます。

## 目指す使い方

政府APIから企業情報を取得し、企業の公式サイトから求人候補を集めます。利用者は職種と勤務地で候補を絞り込み、結果カードから募集ページを開けます。カードには確認日時を記載し、最新の募集状況は元のページで確認できるようにします。

## 練習問題で確認したこと

- サンプルの求人一覧を職種と勤務地の両方で絞り込む。
- 政府APIの応答を想定したサンプルJSONから企業一覧を取り出す。

政府APIとの接続、公式サイトからの求人候補の抽出、Web画面は今後の工程で実装します。

## 練習問題を実行する

Python 3を使い、このリポジトリのルートで実行します。サンプルはPythonの標準ライブラリだけで動きます。`-X utf8` は日本語の出力にUTF-8を使うための指定です。

```powershell
python -X utf8 training/lesson3.py
python -X utf8 training/lesson4.py
```

1つ目は「エンジニア・東京都」に一致するC社のサンプル求人を表示します。2つ目は架空のAPI応答から取り出したA社とB社の企業情報を表示します。
